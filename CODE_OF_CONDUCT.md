# Code of Conduct

AgentChainer follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus on what's best for the project and its users.
Harassment, personal attacks and discriminatory language aren't tolerated in issues, pull requests, discussions or any
other project space.

## Reporting

To report a Code of Conduct concern privately, use
**[Security → Report a vulnerability](https://github.com/hafizhrf/AgentChainer/security/advisories/new)** and start the
title with `[Conduct]`. That channel is private to the maintainers. Reports are handled confidentially, and the
enforcement guidelines of the Contributor Covenant apply.
