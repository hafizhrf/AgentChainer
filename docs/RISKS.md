# AgentChainer — Risk Register

> Review at every milestone boundary. Likelihood and impact are rated **L/M/H**. When a trigger fires, the owner updates
> the mitigation or opens an ADR.

| ID | Risk | L | I | Mitigation | Trigger to act | Owner |
|---|---|---|---|---|---|---|
| R-01 | **Auth policy ambiguity.** Anthropic forbids third parties from offering Claude.ai login, routing requests through subscription credentials *on behalf of* users, or handling credentials. Developers building on the Agent SDK "should use API key authentication". The [legal page](https://code.claude.com/docs/en/legal-and-compliance) also says the policy does not prevent an end user from signing in to the **unmodified** Claude Code binary with their own subscription. | M | H | The app never implements, automates or proxies login, and never reads or stores credentials. It runs the user's own unmodified CLI and never restricts its sign-in methods. Follow the name and logo rules ([ADR-0002](adr/0002-auth-and-branding.md)). Re-read the legal page every release. Ask Anthropic in writing (M0-22). Document API key, Bedrock and Vertex as alternatives. | Policy text changes; Anthropic contacts us | Owner |
| R-02 | **Overlap with Claude Code Desktop.** Anthropic's app already covers sessions, worktrees, subagent pane, diff and PR/CI. | H | M | Focus on the differentiators (bootstrap, contracts and evidence, workflow graph, open source, Linux). Make outputs plain files usable from any Claude surface. Review their changelog monthly. | They ship bootstrap- or contract-like features | Owner |
| R-03 | **SDK/CLI churn** breaks event parsing or options. | H | M | Pin the SDK. A single normalization layer. Recorded-fixture contract tests. Weekly drift job (X-05). Compatibility matrix. | Drift job fails | Maintainers |
| R-04 | **User's CLI version mismatch.** We use the user's binary, not one we bundle. | M | M | Minimum version enforced in the health check (S5). Clear "update" guidance. Degrade gracefully on missing features. | Support issues mention versions | Maintainers |
| R-05 | **Internal transcript format changes** (JSONL). | M | M | Never parse JSONL; SDK session APIs only ([ADR-0004](adr/0004-session-data.md)). | — | Maintainers |
| R-06 | **Sidecar packaging fails** on an OS (single-exe Node, native modules). | L | H | **Mitigated (S1):** Node SEA works and loads the downloaded SDK. Verified end to end on macOS, and sidecar + SDK download covered by CI on Windows and Ubuntu. No native addons in the sidecar. Electron fallback ([ADR-0001](adr/0001-desktop-stack.md)). New residual risk: sidecar size ~117 MB per platform. | CI sidecar smoke fails on an OS | Owner |
| R-07 | **Code signing cost and complexity** (Apple $99/yr, notarizing embedded binaries; Windows SmartScreen). | H | M | Unsigned dev builds with documented workarounds until R1. Decide the budget at R1-03. Azure Artifact Signing for Windows. | Before the first public release | Owner |
| R-08 | **Catalog supply chain:** a malicious or compromised skill, plugin or MCP update. | M | H | Pinned SHA + hash, trust tiers, reviews, previews, no upstream installers, update PRs ([ADR-0005](adr/0005-catalog-trust-model.md)). | Upstream security advisory | Maintainers |
| R-09 | **Prompt injection** from repo or web content leads the agent to run destructive or exfiltrating commands. | M | H | Safe profile by default, `PreToolUse` denylist, approvals for Bash outside the allowlist, no auto deploys. Use Claude Code sandboxing where available (verify). Threat model (X-01). | Incident or report | Maintainers |
| R-10 | **Runaway cost or usage**, especially with parallel subagents. | M | M | Default `maxBudgetUsd`, per-tier caps (M3), visible running cost, concurrency limits. | Users report surprise bills or limits | Maintainers |
| R-11 | **SDK redistribution terms.** The SDK is "All rights reserved", and its terms grant no redistribution right (M0-03, 2026-10-28). | — | H | **Mitigated by design:** the SDK is not bundled. The sidecar downloads the pinned version from npm on first run and verifies its integrity ([ADR-0003](adr/0003-agent-runtime-and-ipc.md)). New residual risks: first-run network, proxies, and npm availability (covered in S1). | Anthropic grants written permission to bundle (M0-22) | Owner |
| R-12 | **Scope creep.** The vision spans an editor, orchestration, CI/CD, deploy and evals. | H | H | Strict milestone exit criteria. P1/P2 features need a design doc first. Non-goals in the [PRD](PRD.md#7-non-goals-v0x). | A milestone slips by more than 50% | Owner |
| R-13 | **Single-maintainer bandwidth.** | H | M | Small vertical slices, good-first-issues, thorough docs and CLAUDE.md so agents and contributors can help. | Stalled for more than 4 weeks | Owner |
| R-14 | **WebView differences** (WKWebView / WebView2 / WebKitGTK): rendering and performance of large diffs and graphs, especially on Linux. | M | M | Test all 3 from M0. Virtualize lists. Performance budgets (X-07). | Perf budget fails on one OS | Maintainers |
| R-15 | **GUI env/PATH:** a Finder- or launcher-started app can't see the shell PATH or env, so it can't find `claude` or the user's API key env. | H | M | Login-shell env resolution, known install locations, binary path setting ([ARCHITECTURE §3](ARCHITECTURE.md#3-locating-claude-and-the-users-environment)). Covered in the tutorial. | S1/S5 findings | Maintainers |
| R-16 | **Windows + WSL:** a CLI installed inside WSL isn't reachable from the Windows app. | M | L | v0.1 supports a native Windows install only, stated in the tutorial. Evaluate WSL later. | User demand | Maintainers |
| R-17 | **Generated CI/tests are wrong or flaky**, which hurts trust. | M | H | The verifier runs everything. Templates are tested on fixtures. Bounded repair loop. The report never claims unverified success. | M2-E2 below target | Maintainers |
